# 資訊公益營 - zlcsc X FunBrain
Date：2024.7/1～7/5 <br/>
為期五天的課程，各個學員都認真的學習了充分的網頁設計知識，彼此也越來越熟悉成為好友。 <br/>

經過了這五天，不止學員們，工作人員也收獲良多，不管在教學、事情處理方面或是待人處事都變得更加進步，感謝各位學員的參與，讓我們大家有這個機會學習！ <br/>
讓中崙資研更加進步！

## 課程內容：
- Day1: 基礎html介紹 <br/>
讓學生們彼此熟識後，接下來就開始精彩的課程！帶著同學們先了解網頁的各個部分！
- Day2: html各個標籤 <br/>
進一步的向各個學員介紹每一個標籤的功能，讓他們更了解如何寫出網站
- Day3: 基礎CSS介紹 <br/>
教完html後，進一步的跟大家講解使用CSS幫忙基礎的網頁美編及排版！
- Day4: 進階CSS介紹 <br/>
開始進行網頁的美化啦～首先我們帶領學員創建css檔案，接著就讓學員試著更改文字顏色、背景顏色，讓網頁的視覺感更上一層樓！
- Day5: 專案實作 <br/>
經過前四天的學習，讓學員們運用學習到的新知，自己創作出屬於自己的網頁！
